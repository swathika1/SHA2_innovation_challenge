## 🚀 How It Works

### User Flow
1. Patient clicks "Start Session"
2. Selects exercises
3. Clicks "Start Session" button
4. **NEW**: Modal appears with 2 options
   - General Rehabilitation (existing)
   - Low Back Pain Program (KERAAL)
5. User selects one
6. Session starts with chosen pipeline
7. Real-time feedback and rep counting
8. Session completes

### Technical Flow
```
Frame from Webcam
    ↓
/api/live_feedback_keraal
    ↓
BlazePose Extract (33 landmarks)
    ↓
Normalize (hip center + torso scaling)
    ↓
Add to 48-frame Rolling Buffer
    ↓
If Buffer Full:
  - Predict Exercise (CTK/ELK/RTK)
  - Predict Correctness (0-1)
  - Compute Score (correctness × 50)
  - Check Threshold (>= 0.55)
  - Count Reps (20 frames each)
    ↓
Return Response
    ↓
Update UI (Score, Status, Reps)
```

## 🔧 Technical Specifications

### KERAAL Pipeline
- **Language**: Python
- **Framework**: TensorFlow/Keras
- **Pose Model**: MediaPipe BlazePose
- **Window Size**: 48 frames
- **Landmarks**: 33 (x, y, z)
- **Normalization**: Hip center + torso scaling
- **Inference**: ~30-50ms per frame
- **Latency**: ~1.6s to first prediction (buffer fill)

### Frontend Integration
- **Language**: JavaScript (vanilla)
- **Modal**: Custom HTML/CSS
- **Event System**: CustomEvent API
- **Polling**: 500ms interval
- **Compatibility**: All modern browsers

### Flask Integration

- **Framework**: Flask
- **API Style**: REST
- **Response Format**: JSON
- **Error Handling**: Comprehensive
